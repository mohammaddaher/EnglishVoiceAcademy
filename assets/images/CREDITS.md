## Replacing a photo with an academy photo

1. Save the new photo in this folder with the **same file name** (JPEG, about 1400–2000 px wide, under ~250 KB).
2. If its proportions differ, update the `width` and `height` attributes on the matching `<img>` in
   both `/en/index.html` and `/ar/index.html` (the layout crops images automatically).
3. Update the English and Arabic `alt` text to describe the new photo.
4. Once a real academy photo replaces a stock one, the footer note about "illustrative stock images"
   can be removed when no stock photos remain.
